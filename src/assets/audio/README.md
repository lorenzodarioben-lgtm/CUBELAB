# Cube turn recordings

The six source files in `source/` are high-quality MP3 previews of **Rubik Cube Turn 4–9** by [SpaceJoe on Freesound](https://freesound.org/people/SpaceJoe/packs/27490/). Each recording is [CC0](https://creativecommons.org/publicdomain/zero/1.0/): [4](https://freesound.org/people/SpaceJoe/sounds/486580/), [5](https://freesound.org/people/SpaceJoe/sounds/486581/), [6](https://freesound.org/people/SpaceJoe/sounds/486582/), [7](https://freesound.org/people/SpaceJoe/sounds/486583/), [8](https://freesound.org/people/SpaceJoe/sounds/486584/), [9](https://freesound.org/people/SpaceJoe/sounds/486585/).

`cube-turn-bank.wav` and `segments.json` are derived from those files by `node scripts/build-cube-samples.mjs` (set `CUBELAB_USE_CHROME=1` to use an installed Chrome instead of Playwright's bundled Chromium). The script trims the recorded slide and contact portions, removes low-frequency handling noise, joins different sliding excerpts with short crossfades, and levels the clips. The sliding loops receive light peak compression and treble damping so the quiet glide stays audible between clicks. The app embeds this compact PCM bank so the first enabled turn plays without a fetch or decode delay.
